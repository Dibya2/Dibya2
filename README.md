## 👨‍💻 About Me

I work on building, operating and improving reliable infrastructure. My interests span DevOps, datacenter operations, virtualization, storage, database high availability and infrastructure automation.

- Linux server administration and service operations
- Datacenter setup, server deployment and OS hardening
- Virtualization and private cloud with Proxmox VE and Apache CloudStack
- Compute, storage, backup and disaster recovery workflows
- PostgreSQL high availability, replication and failover concepts
- Monitoring, alerting and infrastructure troubleshooting
- Automation, CI/CD and infrastructure as code

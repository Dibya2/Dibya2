## 🌌 About Me

I'm a DevOps and infrastructure professional interested in building reliable, scalable and automated systems. My work and learning interests include datacenter operations, virtualization, storage, database high availability, monitoring and infrastructure automation.

- 🏢 Datacenter operations, server deployment and Linux administration
- ☁️ Virtualization and private cloud with **Proxmox VE** and **Apache CloudStack**
- 💾 Compute, storage, backup and disaster recovery workflows
- 🛡️ PostgreSQL high availability, replication and failover concepts
- 📈 Monitoring and observability with **Prometheus**, **Grafana** and **Alertmanager**
- ⚙️ CI/CD, containers and infrastructure automation
- 💻 Exploring **Go**, SRE practices and distributed infrastructure
